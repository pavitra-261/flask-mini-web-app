# Flask Notes App

A simple and user-friendly Notes Application built using Flask. This project allows users to add, update, and delete notes through a clean web interface.

## Features

* Add Notes
* View Notes
* Update Notes
* Delete Notes
* Responsive UI with Bootstrap
* Custom Styling with CSS

## Technologies Used

* Python
* Flask
* HTML
* CSS
* Bootstrap

## Installation

1. Install Flask

```bash
pip install flask
```

2. Run the application

```bash
python app.py
```

3. Open in browser

```text
http://127.0.0.1:5000
```
